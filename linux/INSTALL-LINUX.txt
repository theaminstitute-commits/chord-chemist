CHORD CHEMIST for Linux Mint / Ubuntu - pick ONE of these
==========================================================

1) chord-chemist_0.6.1_all.deb   (recommended; newest version)
   Double-click it. Mint's Package Installer opens: click "Install Package"
   and enter your password. Chord Chemist then appears in the menu under
   Sound & Video and Education.
   Remove later with:  sudo apt remove chord-chemist

2) ChordChemist.run   (no install)
   Right-click > Properties > Permissions > tick "Allow executing file as
   program". Then double-click it and choose "Run".
   (Google Drive downloads always lose that permission, so this step is needed once.)

3) ChordChemist-linux.zip
   The same app as a folder with install.sh (per-user, no password).

All three open the app in its own window when Chromium or Google Chrome is
installed (sudo apt install chromium); otherwise it opens in Firefox.
Works offline. Saved progressions stay on this computer.
